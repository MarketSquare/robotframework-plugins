# rf-agentskills has moved to robotframework-plugins

This installer is now **[robotframework-plugins](https://pypi.org/project/robotframework-plugins/)**, from [MarketSquare/robotframework-plugins](https://github.com/MarketSquare/robotframework-plugins). Switch with:

```bash
uvx robotframework-plugins install        # instead of: uvx rf-agentskills install
```

This last release, 0.9.0, installs `robotframework-plugins` and forwards the `rf-agentskills` command to it with the same arguments, after a one-line notice. There will be no further `rf-agentskills` release.
