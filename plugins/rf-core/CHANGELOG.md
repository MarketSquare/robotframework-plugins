# Changelog

The `rf-core` plugin, versioned on its own (`rf-core--v<version>` tags); see `RELEASING.md` at the repository root.

## 1.0.0 (unreleased)

First release, split out of `rf-agentskills` 3.0.0 with no content changes: `rf-language`, `rf-setup` and `rf-python-library`, the `rf-test-architect`, `rf-debug-expert` and `rf-migration-guide` subagents, and all hooks. Skill names are unchanged; their plugin prefix is now `rf-core:` instead of `rf-agentskills:`, for example `/rf-core:rf-language`.
