# Changelog

The `rf-web` plugin, versioned on its own (`rf-web--v<version>` tags); see `RELEASING.md` at the repository root.

## 1.0.0 (unreleased)

First release, split out of `rf-agentskills` 3.0.0 with no content changes: `rf-browser` and `rf-selenium`. It depends on `rf-core` `^1.0`. Skill names are unchanged; their plugin prefix is now `rf-web:` instead of `rf-agentskills:`, for example `/rf-web:rf-browser`.
